# System Decommission Checklist

## Authorization

- [ ] Owner approved retirement
- [ ] Dependencies and consumers confirmed
- [ ] Legal, retention, and security requirements reviewed
- [ ] Change and rollback windows approved

## Data and access

- [ ] Required data exported and validated
- [ ] Final backup created with an expiration owner
- [ ] User, service, vendor, and emergency access revoked
- [ ] Secrets, certificates, keys, and tokens rotated or destroyed

## Technical removal

- [ ] Monitoring, alerts, jobs, integrations, and automation removed
- [ ] DNS, load balancer, firewall, proxy, and routing entries removed
- [ ] Licenses, subscriptions, compute, storage, and backups released
- [ ] Configuration-management and inventory records updated

## Closeout

- [ ] Logs and evidence retained as required
- [ ] Documentation marked retired
- [ ] Stakeholders notified
- [ ] Cost savings and residual risks recorded
- [ ] Final validation confirms no remaining dependency
